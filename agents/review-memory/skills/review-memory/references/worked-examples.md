# Примеры ревью памяти

Используй эти примеры для выбора правок и формата ответа. Примеры показывают
структуру решения, а не готовые сведения для переноса в память.

## 1. Общие правила и проектный контекст

### Предложенная копия

`AGENTS.md`:

```markdown
# Правила
- Писать код с docstrings на русском языке.

## Работа с проектом
- В этом проекте не менять исходный файл без разрешения.
```

`USER_PREFERENCES.md`:

```markdown
# Предпочтения
- Для текущего задания нужен подробный визуальный макет.
```

### Правильная правка

`AGENTS.md`:

```markdown
# Правила
- Писать код с docstrings на русском языке.
```

Проектное ограничение переносится в личную wiki только при будущей пользе.
Условие одного задания удаляется из `USER_PREFERENCES.md`: оно не доказывает
предпочтение пользователя для других задач.

### Правильный ответ

```json
{"decision":"accepted","summary":"Исправлены AGENTS.md и USER_PREFERENCES.md: из них удалены сведения с ограниченной областью действия. Общее правило сохранено; проектный контекст перенесён в личную wiki.","findings":[]}
```

## 2. Обобщение подтверждённого предпочтения

### Материалы

В диалоге пользователь несколько раз просит показывать законченные части при
работе над большой задачей. В предложенной памяти записано предположение о том,
что пользователь выбирает скорость вместо качества.

### Правильная правка

```markdown
# Предпочтения
- При работе над большой задачей показывать промежуточные результаты.
```

Предположение о причинах выбора удаляется: пользователь его не подтверждал.

### Правильный ответ

```json
{"decision":"accepted","summary":"В USER_PREFERENCES.md оставлено подтверждённое предпочтение о промежуточных результатах; неподтверждённый вывод о мотивах пользователя удалён.","findings":[]}
```

## 3. Недостаточно материалов для разрешения противоречия

### Материалы

В прежней памяти есть общее правило. Новый отчёт содержит несовместимое правило,
но не показывает, отменял ли пользователь прежнее.

### Правильная правка

Не удаляй прежнее правило и не выбирай один вариант самостоятельно. Не меняй
копию в спорной части.

### Правильный ответ

```json
{"decision":"needs_resolution","summary":"Проверена предложенная память; противоречие не исправлено без основания для выбора одного правила.","findings":[{"file":"AGENTS.md","problem":"Два правила несовместимы, а явной отмены прежнего правила в материалах нет.","change":"Нужно уточнение пользователя или материал с явным изменением правила."}]}
```

## Формат ответа

Верный ответ начинается с `{` и заканчивается `}`. Не добавляй к нему
поясняющий текст, Markdown-ограждения или отметки о завершении проверки.
