# Проверка изменений памяти

## Задача

Проверь пригодность предложенной памяти к использованию. Найди ошибки, способные привести рабочего агента к неверному решению, повторным уточнениям или избыточным действиям. Проверь согласованность новой и прежней версии. При разрешении на запись исправляй выявленные ошибки в указанной рабочей копии.

## Вход

- прежняя и предложенная версии памяти;
- перечень затронутых файлов;
- доступные отчёты с извлечёнными сведениями и описанием выполненных проверок;
- разрешённая копия для исправлений.

Начни с изменённых утверждений и непосредственно связанных записей. Доступные материалы анализа используй для проверки спорного смысла; массовое перечитывание исходных диалогов в проверку не входит.

## Проверка

1. **Факты и определения.** Сверь утверждения с предоставленными сведениями и между собой. Проверь значения терминов, формулы, численные результаты, точные имена полей.
2. **Условия действия.** Сравни версии, периоды, проекты, исключения и статусы «реализовано / планируется / предположение». При одинаковых условиях найди противоречия; разные области сохрани раздельно.
3. **Сохранность смысла.** Проверь, что обновление не удалило полезное прежнее знание, не расширило единичный эпизод до универсального правила и не превратило предположение в факт.
4. **Границы файлов.** В `AGENTS.md` проверь общие инструкции, в `USER_PREFERENCES.md` — устойчивые предпочтения, в личной wiki — проектный контекст, в предметной wiki — определения, в Cases — конкретные эпизоды, в Skills — воспроизводимые процедуры.
5. **Практическая применимость.** Для нового или существенно изменённого Skill проверь достаточность входов, связность шагов, наблюдаемость развилок, уместность обязательных проверок и достаточность результата. Найди действия, которые безусловно предписаны при запросе, где они не нужны.
6. **Связи и файлы.** Проверь изменённые ссылки, YAML-заголовки и доступность необходимых локальных материалов; исключи секреты и лишние персональные данные.

## Исправление

Вноси минимальные исправления, которые прямо следуют из имеющихся материалов: уточни версию, область, численное значение, условие или формулировку действия; восстанови утраченное полезное сведение; убери ошибочный дубль.

Если для разрешения противоречия не хватает сведений, сохрани установленную часть и опиши открытый вопрос. Не добавляй новые неподтверждённые алгоритмы, формулы или проверки.

Используемые материалы позволяют проверять содержание на данном этапе; итоговая память остаётся самостоятельной. Не дополняй её ссылками на исходные чаты, номера сообщений и журналы доказательств.

## Результат

Верни один JSON-объект:

```json
{
  "decision": "accepted | changes_requested | needs_resolution",
  "summary": "Проверенные изменения, выполненные точечные исправления и оставшиеся риски",
  "findings": [
    {
      "file": "путь",
      "problem": "конкретное оставшееся противоречие или неточность и условия",
      "change": "необходимая правка либо вопрос для разрешения"
    }
  ]
}
```

- `accepted` — существенных оставшихся проблем нет; `findings` пуст.
- `changes_requested` — известные исправления ещё нужно внести.
- `needs_resolution` — существуют несовместимые утверждения, выбор между которыми требует дополнительных сведений.

Если предложенный каталог уже исправлен в пределах разрешённой копии, оцени итоговое состояние. Отрази выполненные исправления в `summary`.

## Завершение

Перечитай изменённые фрагменты и связанные определения. Проверь исправления и итоговую согласованность. Ревью завершается оценкой корректности памяти; эффективность повторного выполнения задачи по этому Skill не измеряется.

При затруднениях со смысловыми конфликтами используй [пограничные примеры](references/examples.md).
