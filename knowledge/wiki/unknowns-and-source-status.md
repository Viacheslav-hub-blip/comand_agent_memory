# Отсутствие строки, горизонт наблюдения и статус источника

## Три состояния вместо двух

Для сущности в справочнике заключений или платежей различаются:

1. **известное значение** — есть строка с заключением или денежным событием;
2. **неизвестность** — строки нет, но она может появиться позже; по словарю отсутствие строки в `fraud_labels` означает неизвестный исход, а не `legitimate`;
3. **отсутствие навсегда** — по ограниченному снимку не устанавливается.

Отсюда же: «нет проведённых платежей в снимке» — не то же самое, что ноль платежей или «ожидание загрузки».

## Горизонт наблюдения

Любое «нет» ограничено горизонтом снимка; максимальные наблюдаемые даты по источникам фиксируются явно. В учебном снимке: `decision_events` до 2026-10-04 08:01, `fraud_labels` до 2026-10-06 12:00.

## Ревизии заключений

Появление заключения не равно окончательному заключению: `fraud_labels` — история версий. На срез `T` берётся последняя строка с `recorded_at < T`, при равном времени — `label_id DESC`. Пример ревизии в снимке: по A001 первичное `confirmed_fraud` (2026-10-03 09:00) переписано на `legitimate` (2026-10-06 12:00). Причина пересмотра по материалам не устанавливается — фиксируется только факт ревизии и её дата.

## Статус источника важнее свежести

Утверждения в рабочих заметках различаются по полномочиям:

- **утверждённое правило** — действует как норматив;
- **наблюдение** — единичная оценка по данным;
- **черновик планирования** — намерение без полномочий;
- **отсутствует** — сведения не установлены.

Более свежая заметка не делает предыдущую оценку обязательной. При отсутствии утверждения пишется «не установлено», а не подставляется ближайшая по дате оценка.

## SLA разметки заключений

Утверждённого SLA в материалах нет. «Обычно метки успевают к D+3» (2026-10-05) — наблюдение без базы дней и точки отсчёта; «D+5» (2026-10-06) — черновик планирования. Владелец, уполномоченный утвердить SLA, не назван. Гарантированный срок заказчику по заключениям обещать нельзя; допустимая формулировка — ориентир около двух суток с оговоркой об отсутствии гарантии.
