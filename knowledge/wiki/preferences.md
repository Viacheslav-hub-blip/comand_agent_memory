# Предпочтения пользователя

## Инструменты анализа

- Для анализа данных на Python предпочтителен Polars. Если Polars недоступен, пакеты
  не устанавливать: использовать pandas, если он уже есть в окружении, иначе —
  стандартный Python.
- Дополнительные зависимости не устанавливаются: используются только уже доступные
  в окружении инструменты и библиотеки.
- Предпочтение pandas — личное и рабочее; оно не требует использовать pandas
  в общих артефактах, документации или рекомендациях коллегам.

## SQL

- В рабочих запросах предпочтительны именованные CTE и явный список колонок
  вместо `SELECT *`.

## Представление метрик

- Рядом с долями и процентами указывать абсолютные размеры групп.
- Для оценки правил показывать precision, recall на размеченной части, coverage
  и число неизвестных срабатываний — обязательно со знаменателями каждой метрики.
- Отдельно показывать долю размеченных заявок в когорте.
- При сравнении исторического среза с пересчётом выводить только те заявки,
  по которым результаты различаются.
- При анализе изменения метрик правил разделять вклад изменения состава
  срабатываний и вклад изменения разметки.

## Формат процедуры

- Для оценки правил предпочтительна переносимая процедура: зафиксировать когорту
  и дату знания, проверить пригодность данных, полноту и уникальность меток,
  собрать сравнимые группы, посчитать метрики с неизвестными отдельно, разобрать
  ограничения и только затем обсуждать следующий эксперимент.
