# Диагностика расхождения в данных: альтернативы проверяются на данных

- Ситуация: две цифры по одному и тому же периоду расходятся, и нужно объяснить
  причину, не переделывая правила расчёта под нужный ответ.
- Причина: расхождение может давать любая из нескольких причин — задержка
  появления данных, другой срез времени, разный состав когорты, ошибочный выбор
  записи; по одному симптому причина не определяется, а «более свежее число»
  не значит «более верное».
- Решение: придерживаться процесса: зафиксировать симптом и семантику времени;
  для расхождений по истории решений механизмы классифицируются по двум временам
  записи (см. [режимы среза](knowledge-vs-recompute-modes.md));
  проверить доступность и свежесть источников; локализовать различие до конкретных
  записей; проверить альтернативные причины различающими проверками; отделить
  обходной путь от исправления. Статус источника учитывать, а не выбирать число
  по свежести; правила среза не менять ради совпадения цифр; не объявлять любую
  задержку отсутствием данных навсегда.
- Проверка: расхождение объяснено конкретными записями и проверенной причиной;
  альтернативные объяснения либо исключены проверками, либо явно оставлены
  открытыми; правила расчёта не изменялись.
- Границы: окончательный ответ «источник не содержит данных» требует подтверждения
  владельцем источника. Диагностика не даёт права отправлять сообщения от имени
  пользователя без явного указания.
