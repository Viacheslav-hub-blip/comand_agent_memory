# Отсутствие предпочитаемой библиотеки — работа без установки зависимостей

- Ситуация: предпочтительный инструмент (например, Polars) отсутствует
  (`ModuleNotFoundError`), а установка пакетов по условию задачи недопустима.
- Причина: окружение не содержит нужную библиотеку, а установка зависимостей
  запрещена или не предусмотрена; попытка поставить пакет меняет окружение
  и делает расчёт невоспроизводимым у других участников.
- Решение: сначала проверить доступность предпочитаемого инструмента; при его
  отсутствии использовать уже установленную альтернативу (например, pandas),
  иначе — стандартную библиотеку (`csv`, `collections`, `os`). Расчёт писать
  воспроизводимым скриптом, не устанавливая ничего молча. При переходе сохранять
  семантику времени, типов и разрешения равного времени — она важнее синтаксиса
  библиотеки.
- Проверка: скрипт выполнился с кодом 0 и сформировал ожидаемые таблицы и сводку;
  расчёт не зависит от отсутствующей библиотеки.
- Границы: стандартная библиотека многословнее и медленнее на сложной аналитике
  и больших снимках; для больших объёмов нужен согласованный с командой
  инструмент. Приоритет между pandas и стандартным Python задаётся предпочтением
  пользователя и наличием библиотеки в окружении.
