# Сумма запрошенных сумм — не выдача и не одобренная сумма

- Ситуация: запрос суммирует номинальную или запрошенную величину и называет
  результат «суммой одобренного».
- Причина: запрошенная величина — не платёж и не факт выдачи; денежные факты живут
  в отдельном реестре платежей с собственным временем события (`booked_at`).
- Решение: денежные метрики считать по платежам (выдача минус возврат,
  по `booked_at`) отдельными строками и не смешивать с состоянием решения
  по заявке; не называть сумму запросов одобренной.
- Проверка: документация явно разделяет запрошенную сумму и платежи; денежные
  показатели в отчёте выводятся из реестра платежей.
- Границы: применимо там, где есть отдельный реестр денежных операций
  с собственным временем события; иначе сумму запросов нельзя трактовать как
  движение денег.
