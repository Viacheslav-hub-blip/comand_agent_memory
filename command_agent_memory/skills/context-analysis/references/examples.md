# Пограничные примеры извлечения контекста

## Разовый запрет и устойчивый выбор

Пользователь: «В SQL предпочитаю именованные CTE и явные колонки. Обычно использую pandas, но сейчас ничего не устанавливай: достаточно csv и sqlite3».

Подходящий результат:

```markdown
## Предпочтения
- Для рабочего SQL пользователь предпочитает именованные CTE и явный список колонок.
- Для обработки данных в Python пользователь обычно предпочитает pandas.
```

Запрет установки библиотек относится к одному запуску. Добавляй его в проектный контекст только тогда, когда работа продолжается и ограничение всё ещё применимо.

## Точные определения и версии

В документации продукта «Север» `requested_amount_rub` означает запрошенную сумму, а не платежи. Определение `approval_rate` различается по версиям: `v1` включает тестовые заявки, `v2` исключает.

```markdown
## Определения и предметные правила
- **applications.requested_amount_rub** («Север»): сумма запроса клиента, не фактическая выдача.
- **approval_rate v1** («Север»): одобренные заявки / все зарегистрированные заявки когорты, включая тестовые.
- **approval_rate v2** («Север»): одобренные реальные заявки / все реальные зарегистрированные заявки когорты; `is_test=1` исключается из обеих частей.
```

## Установленный проектный контекст

```markdown
## Личный и проектный контекст
- **Отчётность «Север»**: `decision_events` хранит несколько событий по `application_id`; `occurred_at` задаёт бизнес-время, `loaded_at` — время появления записи.
```

Детальную историю изменений статусов сохраняй, только если нужна для продолжения именно этого проекта.

## Агентское резюме с ошибкой

Агент записал `applications.in_scope_v2`, однако доступная `schema.sql` содержит только `application_id`, `created_at`, `requested_amount_rub`, `is_test`, `channel`. Сохрани подтверждённые поля; объявление `in_scope_v2` установленной частью схемы исключи.

## Исторические артефакты

`outputs/C02/differ.csv` может быть полезен как результат предыдущей задачи проекта, если ожидается продолжение этой задачи. Формулируй «был создан в прежнем рабочем окружении»; доступность проверяется в новом запуске. Временная папка не становится общим правилом хранения результатов.

## Пример отсутствия новой информации

Сырой фрагмент: агент несколько раз запускает `python -c`, получает `SyntaxError`, затем исправляет кавычки; пользователь не задаёт новую инструкцию, финальная задача выполнена.

Результат: не добавляй в память историю команд. Если устойчивое свойство оболочки подтверждено, сохрани только это свойство с областью рабочей среды. Если ни одного нового полезного факта нет, верни `Сведений для обновления памяти не обнаружено.`
