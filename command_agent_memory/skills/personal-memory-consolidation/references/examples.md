## Уточнение статуса

Прежний факт: «Адаптер GigaCode запланирован». Новый подтверждённый факт: «Адаптер GigaCode реализован». Измени статус в существующей проектной статье; оставь актуальные ограничения и реальные версии.

## Проектное описание без обязательной процедуры

Проектная страница может сообщать, что `outputs/C06/run_diagnostics.py` использовался для диагностики определённого инцидента, если проект продолжается. Общую обязательную программу из шести этапов в эту статью не добавляй: в следующей задаче агент должен учитывать её только при соответствующем запросе и доступной реализации.

## Несовместимые значения

Если память содержит `X=10`, а новая информация сообщает `X=12` при той же версии без признака исправления или смены области, сохрани установленную часть, не угадывай актуальное число и обозначь конфликт в итоговом ответе.
