# Проверка локальной передачи знания A → B

Сценарий проверяет получение командного определения другим пользователем на новых
числах. Это синтетический пример, а не оценка качества на широком наборе задач.
Функций и классов в документе нет.

## История пользователя A

В проекте «Ладога» показатель «свободный лимит L7» определяется как общий лимит
минус занятый лимит минус технический резерв. Все величины в тысячах рублей.
Технический резерв обязателен. Определение относится к проекту, а не к личным
предпочтениям. Контрольный пример в истории A: 100 − 20 − 5 = 75.

Для истории A настраивается обычный источник JSONL. Минимальная конфигурация:

```json
{
  "defaults": {"provider": "openrouter", "model": "YOUR_MODEL_ID"},
  "users": [{
    "user_id": "alice",
    "workspace": "./runs/alice",
    "source": {"type": "jsonl", "path": "./history.jsonl"},
    "memory": {"type": "files", "root": "./alice",
               "personal": [], "knowledge": ["knowledge"]}
  }],
  "team": {"root": "./shared", "workspaces": ["./bob"]}
}
```

Каталог `bob` создаётся заранее. Его личный `AGENTS.md` требует уточнять неизвестные
определения и указывать источник известных. Команда запуска —
`python -m command_agent_memory --config memory_pipeline.json`.

## Новая задача пользователя B

> Проект Ладога. Рассчитай свободный лимит L7: общий лимит 137, занятый 29,
> технический резерв 11 (все в тыс. руб.). Укажи определение и источник.
> Если определения нет в доступных материалах, сначала уточни его.

Формула в запрос B не включается. Новый экземпляр агента создаётся для каталога
`bob` через `command_agent_memory.working_agent.create_agent`.
Этот агент подключает командный индекс и skills; статьи доступны файловым
инструментам. Ожидается расчёт **137 − 29 − 11 = 97 тыс. руб.** со ссылкой на
определение в `team_knowledge/`.

Контрольный запуск использует отдельный каталог с тем же личным `AGENTS.md`, но
без `team_knowledge/`. Сохраняются ответы, трассы инструментов и доступный usage.
Один успешный опыт показывает работоспособность пути передачи; он не доказывает
стабильный выигрыш по качеству, времени или токенам.

Проверено 2 ноября 2026 года: B с доставленной памятью прочитал статью определения
через `read_file`, получил 97 тыс. руб. и сослался на командный источник. Контроль
без командной памяти запросил определение. Личный файл B сохранён; хеши четырёх
доставленных документов совпали с источником. Локальные трассы и ограничения опыта:
`data/team-transfer-20261102/REPORT.md`.
