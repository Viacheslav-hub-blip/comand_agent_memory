# Воспроизводимый replay на синтетических данных

Руководство содержит команды и результаты контрольного прогона.
Функций и классов в документе нет.

История содержит одно подтверждённое определение L7. Новая задача использует
другую выборку и сравнивает два свежих запуска одной фабрики. У тестировщика есть
вторая исходная реплика и эталон. Агент получает определение из памяти либо,
при необходимости, открывает его через уточнение.

Скопируйте каталог в игнорируемый каталог `data/`, чтобы опубликованная память
и журналы не изменяли версию примера в Git. Команды выполняются из корня проекта
в активном окружении с дополнением `.[replay]` и настроенным OpenRouter.

```powershell
New-Item -ItemType Directory -Force data | Out-Null
$replayDir = Join-Path 'data' ('portable-replay-' + (Get-Date -Format 'yyyyMMdd-HHmmss-fff'))
Copy-Item -Recurse docs/examples/portable_replay $replayDir
$replayConfig = Join-Path $replayDir 'memory_pipeline.example.json'
python -B -m command_agent_memory --config $replayConfig --validate-only --evaluate-by-replay --json
if ($LASTEXITCODE -eq 0) {
    python -B -m command_agent_memory --config $replayConfig --evaluate-by-replay --json
}
```

В итоговом JSON находится путь `status_file`. Рядом с ним каталог `replay/`
содержит профили, сравнение, трассы двух диалогов и решение оценщика.

## Контрольный прогон 21 ноября 2026 года

Оба свежих запуска штатного DeepAgents-агента получили L7 = 100 и сохранили
отчёт с корректными компонентами. Базовый агент запросил определение,
агент с предложенной памятью использовал его на первом ходу. Оценщик выбрал
кандидата, конвейер опубликовал память в копии учебного проекта.

| Измерение рабочего агента | Прежняя память | Новая память |
| --- | ---: | ---: |
| Реплики пользователя | 2 | 1 |
| Вызовы модели | 7 | 5 |
| Вызовы инструментов | 6 | 5 |
| Входные токены, включая кеш | 36 737 | 26 158 |
| Из них кешированные | 20 736 | 15 488 |
| Выходные токены | 1 305 | 607 |
| Время работы агента, с | 14,40 | 14,66 |

Время и токены относятся к рабочему агенту. Построение памяти, тестировщик и
оценщик используют собственные вызовы модели.

## Контрольный прогон скилла Codex 23 ноября 2026 года

Распакованный скилл провёл тот же опыт на двух независимых штатных сессиях
Codex. Обе получили L7 = 100 с компонентами 150 и 50, а `pending` исключили.
Базовой сессии понадобились две пользовательские реплики. Сессия с новой
памятью использовала определение из своего `AGENTS.md` после первой реплики.
Независимый судья выбрал `candidate`; конвейер опубликовал память.
Токены и число вызовов модели остались `null`: интерфейс субагентов не
передал эти измерения.
