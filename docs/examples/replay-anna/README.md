# Сценарий одного прогона Анны

scenario.json объединяет четыре пользовательские реплики диалога C01.
Исходные данные берутся из user_workspace/synthetic_team/ без прежних результатов.
Каталог reference содержит сохранённый последний ответ и файлы C01.
Он предназначен оценщику и не копируется в рабочую область решающего агента.

reference_metrics получены из chat_logs.db диалога
10ce74a3-7be9-45cd-97fe-5bb56a40ef40. Они относятся ко всему исходному диалогу:
четыре пользовательские реплики, 44 обращения к модели, 54 вызова инструментов.
Время включает весь диалог, а новая проверка выполняет один объединённый запрос.
Исходная модель — deepseek/deepseek-v4.1-flash. Новая модель берётся из settings.py.
Эти условия передаются оценщику, поэтому разность времени не доказывает эффект памяти.

Полная команда и структура журналов: [проверка прогоном](../../replay-evaluation.md).
