# Команда и последовательность

«Север» — вымышленная небольшая команда аналитики заявок и антифрода. Она работает с одним учебным набором данных. Персонам не нужно объяснять агенту устройство системы памяти: они решают свои рабочие задачи.

| Сотрудник | user_id | Роль | Личные особенности | Знания, которые приносит |
|---|---|---|---|---|
| Анна Лебедева | 101 | Бизнес-аналитик | Краткий итог, затем таблица; SQL для сверок | Разница между одобрением, выдачей и чистой выдачей; смысл статусов |
| Борис Ким | 102 | Инженер данных | SQL CTE, явные колонки; Python-обработку делает через pandas | История статусов, поздние загрузки, порядок выбора записи, ограничения источников |
| Вера Соколова | 103 | Аналитик антифрода | Для Python-анализа предпочитает Polars; вместе с долями нужны числитель и знаменатель | Подтверждённые метки, неизвестные исходы, изменение разметки и оценка правил |
| Денис Орлов | 104 | Руководитель аналитики | Короткая записка: вывод, влияние, действие; детали по запросу | Общие соглашения отчётности, пересмотр определения метрики, вопросы владельцам данных |

Предпочтения Бориса и Веры различаются намеренно. При отсутствии библиотек вычисления допустимы через стандартную библиотеку; это ограничение окружения не отменяет предпочтений людей и не должно становиться вечным запретом pandas/Polars.

## Распределённые знания

Анна объясняет смысл показателей; Борис — техническое устройство таблиц; Вера — разметку и ограничения оценки; Денис — утверждённые правила команды. Ни один первый чат не содержит всего эталона.

Необходимость соединять эти сведения — свойство нашего сценария, а не воспроизведение опубликованного benchmark. Маленький размер выбран для ручной проверки и выполнения вычислений без внешних сервисов.
