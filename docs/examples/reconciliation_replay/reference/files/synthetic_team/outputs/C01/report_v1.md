# C01 — отчёт v1 по заявкам за 2026-10-01…02

Определение: **v1** (архивное, опубликовано 2026-10-01; тестовые заявки входят).
Срез знания: **2026-10-03 00:00:00 UTC** (верхняя граница исключена).
Когорта: `created_at` в [2026-10-01 00:00:00, 2026-10-03 00:00:00).
Основание: локальная SQLite `north.db`, собранная по `sql/schema.sql`, CSV загружены стандартным Python. Исходные файлы не изменялись.

## Показатели

| Показатель | Значение |
|---|---|
| Заявок в когорте | 8 (7 реальных + 1 тестовая) |
| Одобрено на срез | 3 (A001, A004, A005) |
| Сумма `requested_amount_rub` по одобренным | 27 000 |
| Выдача (disbursement) | 47 000 |
| Возвраты (refund) | 23 000 |
| Чистая выдача (выдача − возвраты) | 24 000 |
| approval_rate v1 | 3 / 8 = 0.375 |

Денежные величины — по `booked_at < T`; заявочные — по `created_at` в когорте и срезу решений на T. Суммы не обязаны совпадать: «одобрение» — решение по заявке, «выдача» — движение денег; `requested_amount_rub` — запрошенная сумма, не факт перечисления.

## Причины расхождения со старым запросом (6 заявок / 85 000 → 3 заявки / 27 000)

| # | Причина | Заявки | Вклад |
|---|---|---|---|
| 1 | Берётся любое `approved`-событие, а не последний известный на срез статус | A002, A007 | −50 000 |
| 2 | Нет среза по времени появления записи (`loaded_at`) | A006 | −8 000 |
| 3 | `requested_amount_rub` принят за деньги | — | природа величины, не сумма |
| — | Размножение заявок при JOIN | — | 0 (у каждой заявки ≤1 approved-события) |

85 000 − 50 000 − 8 000 = 27 000.
