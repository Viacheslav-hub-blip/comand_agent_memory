# Диалоговый сценарий Анны

Используйте `dialogue_scenario.json`: он ссылается на четыре исходные реплики
C01 и задаёт цель проверки. Каталог reference содержит сохранённый ответ
и файлы результата. Эти материалы доступны тестировщику и оценщику,
а решающий агент получает только исходные данные и выбранные реплики.

При подключении к конвейеру расположите конфигурацию в общем родительском
каталоге сценария и его материалов либо скопируйте связанные материалы под
каталог своей конфигурации. Задайте replay_scenario у пользователя и запустите:

```powershell
python -m command_agent_memory --config memory_pipeline.json --evaluate-by-replay
```

Рабочий агент задаётся полем agent сценария; замените YOUR_WORKER_MODEL_ID.
Модели тестировщика и оценщика выбираются через replay_tester и evaluation.
Условия исходного и нового диалога могут различаться; разность времени сама
по себе не доказывает эффект памяти. [Методика проверки](../../evaluating_memory_with_replay.md).
