# Диалоговый сценарий Анны

Руководство описывает исследовательский replay команды «Север».
Функций и классов в документе нет.

Сценарий требует подготовленного `user_workspace/synthetic_team/` с
исходными файлами. Этот каталог локальный. Для запуска с полным комплектом
входов из проекта используйте [самостоятельный пример](../portable_replay/README.md).
`combined_request_scenario.json` сохраняет постановку одним блоком.
Действующая входная проверка требует отдельных исходных реплик, поэтому
этот вариант получает `skipped`.

Для диалоговой проверки используйте `dialogue_scenario.json`: он ссылается на четыре исходные реплики
C01 и задаёт цель проверки. Эталонный ответ `reference/answer.md` доступен
тестировщику и оценщику. Решающий агент получает исходные данные и выбранные
реплики. Для собственного сценария дополнительные эталонные файлы можно
поместить в `reference/files/`.

При подключении к конвейеру расположите конфигурацию в общем родительском
каталоге сценария и его материалов либо скопируйте связанные материалы под
каталог своей конфигурации. Задайте replay_scenario у пользователя и запустите:

```powershell
python -m command_agent_memory --config memory_pipeline.json --evaluate-by-replay
```

Рабочий агент задаётся полем agent сценария; замените YOUR_WORKER_MODEL_ID.
Модели тестировщика и оценщика выбираются через replay_tester и evaluation.
Текущий конвейер сравнивает два свежих диалога. Сохранённый отчёт Анны используется
для проверки качества. [Методика replay](../../evaluating_memory_with_replay.md).
